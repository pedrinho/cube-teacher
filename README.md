# Cube Teacher

A web app that teaches how to solve the Rubik's cube with the **layer method**
("método de camadas") as taught by Rafael Cinoto in
[Montar Cubo Mágico com histórias](https://cinoto.com.br/cubomagico/metodo-de-camadas-com-historias/).

- **Learn**: one lesson per step, with Cinoto's video, the cases and their moves.
- **Solve my cube**: paint your scrambled cube and follow a step-by-step solution that uses
  the same moves you are learning.

## Development

```sh
npm install
npm run dev      # start the app
npm test         # run the tests
npm run build    # static build in dist/
```
